# SUBSISTENCE — как хай-поли модели попадают в Unity (ModelsHP)

**Коротко: ничего вручную делать не надо.** Пункт меню `Subsistence → 7. Модели: префабы и
Resources` сам замечает хай-поли версии и собирает префабы из них.

## Что где лежит

```
Assets/Subsistence/Models/<имя>.fbx              ← исходные игровые модели (как было)
Assets/Subsistence/ModelsHP/<имя>/
    <имя>_hp.fbx         игровая сетка (та же геометрия, материал с картами)
    <имя>_lod1.fbx       LOD ~55%
    <имя>_lod2.fbx       LOD ~25%
    <имя>_color.png      запечённый albedo (2K крупные / 1K мелочь)
    <имя>_normal.png     запечённые нормали (Tangent)
    <имя>_ao.png         запечённый AO (половинное разрешение)
    <имя>_albedo.png     генерируется редактором: color × AO (создаётся при «7»)
```

## Как работает пункт «7» (Editor/ModelPrefabBuilder.cs)

1. Обходит все FBX в `Assets/Subsistence/Models` (как раньше).
2. Если для модели есть `ModelsHP/<имя>/<имя>_hp.fbx` — **префаб собирается из HP-версии**:
   - материал `HDRP/Lit`: `_BaseColorMap` = albedo (color×AO), `_NormalMap` = нормали;
   - `LODGroup`: LOD0 сама модель (60 % экрана), LOD1 (30 %), LOD2 (10 %);
   - имя префаба то же (`Resources/Models/<имя>.prefab`) — **рантайм-код не меняется**,
     `World/ModelLibrary` грузит как обычно.
3. Модели без HP-версии собираются как раньше (постепенно все переезжают на HP, трекер:
   `docs/HIGHPOLY_TRACKER.md`).

## Что проверить после первого запуска

- Консоль Unity после «7»: в строке «префабов собрано N … из них хай-поли M» — M должно
  равняться числу папок в `ModelsHP`.
- В сцене монстр/оружие в руках — видна детализация (нормали) и мягкие тени щелей (AO в альбедо).
- Окно Game → Stats: draw calls и треугольники — LOD-ы должны резать счётчик вдали от камеры.

## Если что-то не так

- **Серые модели без текстур** — не нашёлся шейдер HDRP/Lit (проект без HDRP-ассета):
  «Subsistence → 5. Создать HDRP Asset», затем «7» заново.
- **Нормали «плоские»** — проверить, что `<имя>_normal.png` импортировался с типом
  *Normal map* (Inspector → Texture Type).
- **Чёрные края/швы** — прислать скрин, подниму margin запекания в `tools/blender/hp_pipeline.py`.

## Памятка песочнице (для ИИ)

Воркспейс Arena имеет лимит снапшота (~128 МБ) и может откатиться к базе. Источник истины —
GitHub-репозиторий. Правила: (1) пушить сразу после каждого готового куска; (2) при сбросе
запускать `bash tools/recover_from_github.sh`; (3) незапушенное — перегенерить конвейером
`bash tools/hp_batch.sh …` (это дёшево, всё детерминировано).
